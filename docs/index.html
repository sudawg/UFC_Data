What this data is — and is not

Coverage and caveats

Read this before drawing conclusions from anything on the site.

  • –
  • –
  • One consensus closing price per fighter. There is no per-sportsbook breakdown, no opening line and no line-movement history in this data — a single closing number per corner is all there is. Anything that would need line movement (steam, CLV, book-to-book arbitrage) cannot be computed here.
  • Implied probabilities are the raw single-side conversion of the American price, so the two corners of a bout sum to more than 100%. That excess is the book's overround, not an edge.
  • Per-fight statistics come from the official scorecards. Cards before roughly 2001 often carry partial or zero strike counts, which drags early accuracy figures toward zero.
About. Built from three CSVs the scraper maintains in the repository: Data/fight_data.csv (cleaned per-fight statistics), Data/fight_data_raw.csv (raw scrape — weight class, referee, title status, finish time) and Data/moneyline.csv (historical closing moneylines). The JSON feeds behind these pages are rebuilt from those files by scripts/build_site_data.py; every number on the site is derived at page load, in your browser.
  • –
  • No external scripts, fonts, trackers or CDN requests: each page is a single self-contained HTML file plus one shared stylesheet and one shared script.
